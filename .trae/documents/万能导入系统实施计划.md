# AI考试：万能导入 —— 多模板自动导入下单系统

## 需求分析

### 项目背景
物流/快递行业需要频繁批量下单，客户提供的Excel模板格式各异（列名不同、列序不同、甚至合并单元格）。需开发一个Web应用，支持多种Excel模板的自动识别与导入，完成批量下单流程。

### 核心字段定义
| 字段名 | 说明 | 必填 |
|--------|------|------|
| 外部编码 | 外部系统订单唯一编号，用于去重 | 否 |
| 发件人姓名 | 寄件人姓名 | 是 |
| 发件人电话 | 寄件人联系方式 | 是 |
| 发件人地址 | 寄件人完整地址 | 是 |
| 收件人姓名 | 收货人姓名 | 是 |
| 收件人电话 | 收货人联系方式 | 是 |
| 收件人地址 | 收货人完整地址 | 是 |
| 重量(kg) | 货物重量，必须为正数 | 是 |
| 件数 | 包裹数量，必须为正整数 | 是 |
| 温层 | 常温/冷藏/冷冻 | 是 |
| 备注 | 附加说明 | 否 |

### 四大功能模块

**模块一：模板管理与文件导入**
- 支持上传Excel文件（.xlsx/.xls），支持拖拽和点击上传
- 支持至少2种不同模板格式的自动识别（不同列名、不同列序）
- 模板记忆学习：手动调整列映射后自动保存规则，下次自动应用
- 导入时显示实时进度条（百分比和当前处理条数/总条数）
- 支持1000条以上数据导入
- 完善的错误处理（文件格式错误、文件为空等）

**模块二：数据预览与编辑**
- 导入后进入预览列表页面，类Excel表格展示
- 表头固定、支持横向滚动、单元格点击可直接编辑
- 行内错误实时校验（必填缺失、电话格式、重量/件数非正数、温层范围）
- 全部错误一次性展示，标注行号、字段名、错误原因
- 外部编码重复检测（同批次内+与已存在数据）
- 支持删除行、新增空行操作
- 支持导出为Excel文件

**模块三：提交下单**
- 有错误的行不允许提交
- 点击"提交下单"后显示上传进度条
- 提交成功后数据持久化到数据库
- 返回提交结果汇总（成功N条、失败N条）

**模块四：已导入运单列表**
- 查看所有历史已导入的运单记录
- 支持按外部编码、收件人姓名、提交时间筛选/搜索
- 支持分页展示

## 技术选型
- **框架**: Next.js 14+ App Router + TypeScript

## 关键技术实现

### 模板自动识别算法
1. 读取Excel表头行
2. 对每个表头列名进行相似度匹配（支持别名映射）
3. 建立列名到系统字段的映射关系
4. 保存映射规则到localStorage（基于表头指纹）

### 实时校验规则
- 必填字段：发件人姓名、电话、地址；收件人姓名、电话、地址；重量、件数、温层
- 格式校验：电话格式、重量正数、件数正整数、温层值范围

### 数据库表设计
```sql
CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  external_code TEXT,
  sender_name TEXT NOT NULL,
  sender_phone TEXT NOT NULL,
  sender_address TEXT NOT NULL,
  receiver_name TEXT NOT NULL,
  receiver_phone TEXT NOT NULL,
  receiver_address TEXT NOT NULL,
  weight FLOAT NOT NULL,
  quantity INT NOT NULL,
  temperature TEXT NOT NULL,
  remark TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```
